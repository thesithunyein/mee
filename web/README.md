# Mee web app

Next.js 16 site and API routes for [Mee](../README.md). It reads static data from `public/data`, which the pipeline generates.

```bash
npm install
npm run dev   # http://localhost:3000
```

Telegram alerts need environment variables. See [`.env.example`](.env.example) and the main [README](../README.md#3-telegram-alerts-optional).
